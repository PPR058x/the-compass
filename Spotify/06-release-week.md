## Milestone context

- 2 August 2026: full album live on Spotify (and Apple Music), synchronized with YouTube, Instagram, Facebook, and TikTok within the same 24-hour window.

- 8 August 2026: end of Release Week — first-week recap content begins transitioning toward Phase 7.
- **Scheduling note (flag, not a change):** 2 August 2026 falls on a **Sunday**. Spotify's global new-release cycle is built around Friday releases ("New Music Friday" and most weekly editorial refreshes). A Sunday release date sits outside that primary weekly editorial moment. This is a flag for the team's awareness only — `CLAUDE.md` fixes the release date and states it should not shift without explicit instruction, so this is not a recommendation to change it, only a note that editorial playlist add timing (see below) may be affected and is worth confirming with the distributor/editorial contact.

## Canvas Concept Briefs

Canvas can now genuinely attach to live tracks — but per the same tracklist-confirmation constraint as earlier phases, these remain **campaign-moment templates** to hand off for track assignment once `ALBUM.md` is finalized, rather than named per-track briefs. Concept only — for Creative Director / video production.

**1. "Release Day" hero moment**
- Motion: the completed Metatron's Cube from the Phase 5 tracklist-reveal Canvas holds steady, then a single warm gold light source ignites at its center and blooms outward to fill the frame before settling back to a calm glow — the "arrival" beat.
- Geometry element: Metatron's Cube, fully resolved.
- Color: black ground, Signature Gold `#D4AF37` structure, Radiant Champagne `#E8D9A0` bloom at ignition.
- Duration feel: 8–10 second loop; the bloom should read as arrival, not explosion — restrained, cinematic, one clean motion.

**2. "First Listen" moment**
- Motion: sound-wave-like concentric rings ripple outward continuously, evoking the album actually playing/being heard for the first time — more active than earlier "pulse" templates, since the album is now real and audible.
- Geometry element: concentric circles / radiating frequency rings, in continuous motion rather than a single pulse.
- Color: black ground, Signature Gold `#D4AF37` rings, Ember Gold `#B8860B` trailing fade.
- Duration feel: 5-second loop, slightly more rhythmic than prior phases' templates — still slow and deliberate, never chaotic.
