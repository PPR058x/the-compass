# assets/images/

All site imagery lives under this one folder, organized by what it's for. No real image files exist yet anywhere below — every path is placeholder-ready.

- `favicon.ico` — browser tab icon for both `index.html` and `epk.html`. Drop it in with this exact name, then set `COMPASS.artist.images.favicon = { src: "assets/images/favicon.ico" }` in `data/artist.js`.
- `artist/` — artist/brand identity images (logo, main, portrait, live) — see that folder's README.
- `releases/albums/`, `releases/singles/`, `releases/eps/` — per-release artwork, one subfolder per release — see `releases/albums/README.md` / `releases/singles/README.md` / `releases/eps/README.md`.
- `press/photos/`, `press/logos/` — press-facing media referenced by `epk.html` — see `press/README.md`.
