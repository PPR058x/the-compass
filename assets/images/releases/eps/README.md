# assets/images/releases/eps/

No EPs exist in the confirmed release catalog yet — this folder is intentionally empty, ready for the first one.

To add an EP: create `assets/images/releases/eps/<release-id>/`, drop in `cover.webp`, and append an entry with `type: "ep"` to the `COMPASS.releases` array in `data/releases.js`. It will automatically appear in the EPK's "EPs" filter — no HTML changes needed.
