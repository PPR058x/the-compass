# prompts/

Reusable **agent prompt templates** — system prompts and task instructions used to run the specialized AI agents defined in `agents/`.

**Not to be confused with `Prompts/`** (capital P, existing folder): that folder holds brand-consistent *image/video/audio generation prompts* for *The Awakening Code* campaign assets. This folder (`prompts/`, lowercase) is for the agent framework itself — the instructions that define how an agent behaves, not creative-asset prompts.

Currently a scaffold — empty until the first agent prompt templates are added. See `docs/ARCHITECTURE.md` for how this fits into the overall system.
