# branding/

Studio-wide and cross-release brand assets and agent-facing brand configuration for The Compass.

This is distinct from `BRAND_BIBLE.md` at the repo root, which remains the source of record for *The Awakening Code*'s specific visual identity, tone of voice, and messaging. This folder is for brand infrastructure that spans the studio as a whole (e.g. future releases beyond this album).

Currently a scaffold — empty. See `docs/ARCHITECTURE.md` for how this fits into the overall system.
