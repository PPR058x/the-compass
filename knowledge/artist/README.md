# knowledge/artist/

Reference facts about the artist(s) behind The Compass — biography, background, career history, collaborators — for agents to draw on across any album or campaign.

Per `CLAUDE.md` §2, any biographical fact that isn't already confirmed elsewhere in the project must be treated as unknown and recorded with a bracketed placeholder (e.g. `[add hometown]`) rather than invented. That rule applies here too: this folder should never contain a fabricated fact, only confirmed ones or explicit placeholders.

Currently empty — artist reference material has not yet been consolidated here. Existing confirmed facts live in `Press/ARTIST_BIO.md` and the root `CLAUDE.md` (§2) until migrated.
