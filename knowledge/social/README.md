# knowledge/social/

Reference knowledge about social platforms — format specs, platform roles, posting conventions, what's worked before — that agents draw on when producing platform content.

Distinct from the top-level `marketing/` (studio-wide marketing infrastructure) and the existing per-platform folders (`Facebook/`, `Instagram/`, `TikTok/`, `YouTube/`, `Spotify/`, `Apple Music/`), which hold actual campaign content. Platform roles for the current campaign are defined in `CONTENT_CALENDAR.md` §4 — this folder is for durable, cross-campaign platform knowledge, not campaign-specific posts.

Currently empty.
