# marketing/

Scaffold for agent-driven marketing work across **The Compass** studio — spanning future releases, not just the current campaign.

The existing, human-curated marketing campaign for *The Awakening Code* stays exactly where it is: `CONTENT_CALENDAR.md`, `RELEASE_PLAN.md`, `Press/`, and the platform folders (`Facebook/`, `Instagram/`, `TikTok/`, `YouTube/`, `Spotify/`, `Apple Music/`) at the repo root are unaffected by this folder. This `marketing/` folder is for studio-wide marketing agent output and cross-release marketing infrastructure going forward.

Currently a scaffold — empty. See `docs/ARCHITECTURE.md` for how this fits into the overall system.
