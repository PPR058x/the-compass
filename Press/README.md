# Press Kit — The Awakening Code

This folder contains press-facing materials for the album *The Awakening Code* by Patrick Pascal Reerink, releasing 2 August 2026.

## Contents

- `ONE_SHEET.md` — single-page fact sheet for quick editor/journalist reference
- `PRESS_RELEASE.md` — official announcement press release template
- `ARTIST_BIO.md` — short and long artist biography templates
- `ARTIST_STATEMENT.md` — first-person statement on the album's concept and meaning
- `FAQ.md` — anticipated press/media questions and answers
- `MEDIA_CONTACT.md` — press contact and media request information

## Important — placeholders before distribution

Several fields throughout this kit are marked with brackets, e.g. `[hometown/origin]`, `[prior releases]`, `[management contact]`. These mark **factual biographical or contact details that must be supplied and verified by Patrick Pascal Reerink or the artist's team** — they were intentionally left as placeholders rather than invented, since press materials must be factually accurate.

Do not distribute any file in this folder to media until all bracketed placeholders have been filled in and reviewed.
